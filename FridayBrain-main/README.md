# 🤖 "F.R.I.D.A.Y" by Brian Griffin And Stewie Griffin
<img width="1780" height="910" alt="image" src="https://github.com/user-attachments/assets/3f4e944d-867e-4088-979b-dd26d0dfda96" />

F.R.I.D.A.Y is an AI-powered desktop voice assistant built with Python and Ollama. It enables natural voice interactions, desktop automation, application launching, browser control, and intelligent conversations through a wake-word activated interface.

## ✨ Features

- 🎤 Wake word detection ("Hey F.R.I.D.A.Y ")
- 🗣️ Speech-to-Text voice recognition
- 🔊 Text-to-Speech responses
- 🧠 AI conversations using Ollama
- 📂 Open desktop applications
- 🌐 Open websites
- 🔋 Battery status
- 🕒 Current time
- ▶️ YouTube search
- 🌦️ Weather support (In Progress)
- 📸 Screenshot support (In Progress)

## 🛠️ Technologies Used

- Python 3
- Ollama
- SpeechRecognition
- PyAudio
- PyAutoGUI
- psutil
- webbrowser
- macOS `say` command

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/F.R.I.D.A.Y.git
cd F.R.I.D.A.Y
```

### Create a virtual environment

```bash
python3 -m venv .venv
```

### Activate the virtual environment

macOS/Linux

```bash
source .venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Install Ollama

Download and install Ollama from:

https://ollama.com

Then pull the model:

```bash
ollama pull llama3.2:3b
```

### Run F.R.I.D.A.Y

```bash
python3 main.py
```

# 🎤 How to Use

After running the project:

Say:

```
Hey F.R.I.D.A.Y
```

F.R.I.D.A.Y will respond:

```
Yes Boss?
```

Now give a command.

### Examples

Open YouTube

```
Hey F.R.I.D.A.Y
Open YouTube
```

Open Chrome

```
Hey F.R.I.D.A.Y
Open Chrome
```

Ask Time

```
Hey F.R.I.D.A.Y
What time is it?
```

Battery Percentage

```
Hey F.R.I.D.A.Y
What's my battery percentage?
```

Search YouTube

```
Hey F.R.I.D.A.Y
Search YouTube for Python tutorials
```

Chat with AI

```
Hey F.R.I.D.A.Y
Explain Machine Learning
```

Exit

```
Hey F.R.I.D.A.Y
Bye
```
